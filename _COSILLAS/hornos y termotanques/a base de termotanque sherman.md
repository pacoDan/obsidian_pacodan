Para reutilizar tu termotanque Sherman de 80 litros, las mejores piezas son el **tanque interno de acero pesado** (ideal para retener calor) y el **conducto de gases de 3 pulgadas (76,2 mm)** para la ventilación. Debes retirar y desechar la lana de vidrio/poliuretano de forma segura y hacer un "fuego de curado" intenso dentro del tanque pelado para quemar esmaltes, galvanizados o residuos antes de cocinar.

**1. Horno "Chileno" (Cámara de cocción aislada)**

- **Concepto:** El fuego se hace debajo. El calor y el humo envuelven el tanque por fuera sin entrar en contacto con la comida, logrando un horneado limpio y parejo.
- **Piezas:** Tanque interno entero (cámara), tubo de 3" (chimenea del domo exterior).
- **Construcción:** Se acuesta el tanque interno. Se le corta una tapa circular en un extremo y se le ponen bisagras. Se construye una bóveda de ladrillos alrededor, dejando un "pasillo" de 5 a 10 cm entre el ladrillo y el tanque para que el fuego fluya.

Plaintext

```
       [Chimenea 3"]
          ||||
     .----||||----.
    /   Espacio    \  <-- Bóveda de Ladrillo
   |  .----------.  |
   |  |  Cámara  |  | <-- Tanque Interno (80L)
   |  |  Cocción |  |
   |  '----------'  |
    \  Calor --->  /
     '----.  .----'
         /    \
       [ FUEGO ]      <-- Cámara de combustión
```

**2. Horno Chulengo / Ahumador Horizontal**

- **Concepto:** Fuego y comida en el mismo compartimento. Ideal para cocciones largas, ahumados o asados. Si le pones tejuelas refractarias en el fondo, funciona excelente para pizzas.
- **Piezas:** Tanque interno cortado a lo largo, tubo de 3" como chimenea directa.
- **Construcción:** Se utiliza el tanque en horizontal. Se corta aproximadamente un tercio del cilindro a lo largo para fabricar la puerta (con bisagras). Se sueldan guías internas de hierro ángulo para apoyar una parrilla.

Plaintext

```
       ||| <-- Tubo 3" (Escape de humo)
   .---|||-------.
  /    Bisagra    \
 | .-------------. |
 | |=============| | <-- Parrilla interna
 | '-------------' |
  \   [ Brasas ]  /  <-- Base del tanque
   '-------------'
     ||       ||     <-- Patas de hierro ángulo
```

**3. Horno Tandoor / Vertical de Barro**

- **Concepto:** Horno de altísima temperatura por radiación. El fuego se hace en el fondo y los alimentos (panes planos, carnes en brochetas) se pegan a las paredes o cuelgan desde arriba.
- **Piezas:** Chapa exterior fina o tanque interno (sin tapa ni base).
- **Construcción:** Se cortan los extremos del tanque para dejar un tubo hueco. Se asienta verticalmente sobre ladrillos dejando una tronera (hueco) inferior para alimentar el fuego. Se reviste el exterior y/o interior con una mezcla gruesa de arcilla, arena y paja (adobe) para crear una masa térmica masiva.

Plaintext

```
      (Boca superior abierta)
        /                \
       ||                || <-- Capa gruesa de Adobe
       |||              ||| <-- Chapa del Termotanque
       |||              |||
       |||              |||
       |||    FUEGO     |||
       |||______________|||
        |   Entrada de   |
        |     Aire       |
```

**Sugerencias de Taller**

- **Corte:** Usa una amoladora angular con disco de corte fino para metal.
- **Fijaciones:** La chapa del tanque interno suele ser lo suficientemente gruesa (aprox. 2-3 mm) para soldar bisagras y perfiles con electrodo (arco manual) o MIG. La chapa exterior blanca (con los stickers de Sherman) es muy fina y tiende a perforarse si se la suelda; es mejor remacharla o usarla solo como encofrado.
- **Pintura:** Una vez finalizado, pinta únicamente el exterior de las partes metálicas expuestas con pintura alta temperatura (soporta hasta 600°C). Nunca pintes el interior.
